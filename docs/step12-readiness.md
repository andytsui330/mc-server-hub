## 還要在 Mac 補驗

- 本輪只接續 Intel Mac；Apple 晶片實機驗收暫緩，維持未驗標示，不列入本輪待執行清單。未來有實機資源時，才另行安排原生操作與開關服驗收。
- 真正 OS 登入啟動：先核將使用的登入項目機制、原基線及影響，再取得同意；登入由使用者本人操作。
- Mac 更新檢查失敗與重試：Windows 結果不可代替。正式設定寫入及本機拒絕代理須另列範圍取得同意。
- 網路下載後的 Gatekeeper 與首次開啟體驗：本機建出的 DMG 沒有相同下載標記，不能冒稱已測。
- Mac 正式更新的下載、驗簽、替換及重新開啟：仍未驗。現有本機 updater 測試入口僅支援 Windows。

重新打包 Mac 前，必須先把要保留的舊 DMG 複製到 bundle 輸出以外並核 SHA；建置工具可能清掉原本 dmg 輸出。Windows 文件收尾會改到程式內嵌更新說明與打包使用說明，因此舊 Mac DMG 仍只能當作先前版本的測試證據，不能聲稱已包含這輪文件。

## 本機可準備的發佈資料

- README 的 Windows／Mac 固定下載入口與限制；兩個入口都只是未上線的預定位置。
- 從 CHANGELOG 的 2.0.0 一節產生共用更新說明，不另外手寫另一版。
- Windows 候選、使用說明、逐套件授權、SBOM 及完整檢查碼；本機候選狀態必須保留「未簽、未正式發佈」。最新文件版候選尚未安裝驗收，不能借用前一包的安裝結果。
- Mac 檔案回到實機後重核；Windows 上引用的 Mac SHA 僅能標為先前實機紀錄，不能當成本輪重新計算。
- 同名 SBOM／授權附件要按平台分開。待上傳清單使用 `SBOM-Windows.cdx.json`／`SBOM-Mac.cdx.json` 與對應平台授權檔名，避免互相覆蓋；最終 SHA 清單要等實際交付檔定案後重算。
