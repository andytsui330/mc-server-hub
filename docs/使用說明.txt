MC 開服平台 使用說明
====================

這個工具讓你在自己的 Windows 或 Mac 電腦上開 Minecraft 伺服器：按一下就開機、關機、看主控台、備份世界。
只在你自己的電腦上運作，別人無法從網路控制它。
目前的版本號顯示在視窗左上角（例如 v1.0.0）。


一、第一次打開（約 2 分鐘）
----------------------------
1. 雙擊「MC開服平台.exe」。第一次會等 5–10 秒才出現視窗。
2. 如果跳出藍色視窗「Windows 已保護您的電腦」：
   按「其他資訊」→「仍要執行」。
   這是因為這個小工具沒有付費買微軟的數位簽章，不是偵測到病毒。
3. 如果防毒軟體擋下或把檔案隔離，請到防毒軟體把它加入允許清單。
   只有在你信任傳給你的人時才這樣做，檔案請向本人索取，不要從來路不明的地方下載。


二、從零建立一台新伺服器（約 5 分鐘）
------------------------------------
1. 按左側清單下方的「建立新伺服器」。
2. 依序填：伺服器名稱、遊戲版本、類型、記憶體、存放位置。
   類型有四種：原版（不裝模組）、Fabric、Forge、NeoForge。想裝模組就選你要用的模組寫的那一種，
   三種模組彼此不互通。某個版本不支援的類型會反灰並寫原因。
   選 Forge 或 NeoForge 時，安裝器會自己連官方網站下載約數百 MB，要 2–10 分鐘，畫面會顯示安裝過程。
3. 畫面會告訴你 Java 夠不夠。如果不夠，點連結下載，一路按下一步裝好，
   再按「裝好了，重新檢查」，平台不用重開。
4. 閱讀並勾選同意 Minecraft 授權合約（EULA）。這一定要你本人同意，工具不會代勾。
5. 按「建立並開機」。工具會從 Mojang／Fabric／Forge／NeoForge 官方網站下載伺服器檔案，第一次開機要產生世界，約 1–3 分鐘。
6. 狀態變成綠色「執行中」，就可以進遊戲了。
   自己這台電腦連線時，「伺服器位址」填 localhost（如果連接埠不是 25565，就填 localhost:連接埠）。


三、加入電腦裡現有的伺服器
--------------------------
1. 按左側清單下方的「加入現有資料夾」，選有 start.bat（或 Forge／NeoForge 的 run.bat）的伺服器資料夾。
2. 連接埠和版本會自動讀取，不用自己設定。
3. 「詳細資訊」裡的「從清單移除」只是從平台拿掉，資料夾和世界都不會被刪除。


四、日常操作
------------
開機：按該伺服器的「開機」按鈕。第一次開可能會問你要不要同意 EULA。
關機：按同一顆按鈕（執行中會變成「關機」）並確認。伺服器會先存檔再關，通常 10–60 秒。
      請不要直接關電腦或用工作管理員結束，可能會壞檔。
下指令：主控台下方輸入框直接打遊戲指令，不用打 /，例如 op 玩家名稱。按 ↑ 可叫回上一個指令。
常用指令：「常用指令」區依分類點一下，在原地填好欄位就送出，不用背指令。
      會影響玩家或世界的指令要按兩次確認；影響全部玩家或整個世界的，要打字確認才會送出。
      按 Ctrl K 可以用關鍵字搜尋指令。
      自己常用的指令可以存進「我的筆記」，之後在常用指令裡點一下就能用。
裝模組：按「開啟資料夾」→「mods 資料夾」，把模組 jar 放進去，重新開機。
      模組要和遊戲版本、伺服器類型（Fabric／Forge／NeoForge）都相符；
      Fabric 的模組大多還要另外放 Fabric API。開不起來時，紅色訊息和主控台最後幾行會寫是哪個模組有問題。
開關機音效：開機成功、開始關機時會響一段「噠噠噠－咚」的提示音，當機時響一聲低音。
      點一般按鈕會有輕輕的「滴」，真的送出指令時是比較沉的「咚」。音量固定，沒有靜音開關（要安靜請調電腦音量）。
      瀏覽器規定：每次開視窗後要先在畫面上點一下，才會有聲音；視窗縮小時聲音可能晚一點到；視窗關掉就不會響。
圖示與顏色：點伺服器名稱左邊的大圖示，可以從 93 個像素圖示和 8 種顏色裡幫這台挑一組，按「套用」才會存。
      左側清單、總覽和名稱都會換成這組圖示和顏色。沒挑過的伺服器顯示草地圖示、依順序配色。
      圖示和顏色存在 hub_config.json；就算改回用 1.0.0 平台開，伺服器和圖示設定都不會受影響（1.0.0 只是不顯示）。
給朋友的資訊：按「詳細資訊」，可以存朋友連線網址、複製一段加入說明（可直接貼 LINE），範本也能自己改。
關掉平台視窗：伺服器照跑。再雙擊 exe 就會回到同一個平台。


五、備份世界
------------
關機狀態下按「備份世界」。開機中按不了，這樣備份才不會只拿到一半。
完成後會顯示檔案數、大小和備份位置，位置在該伺服器資料夾裡的 backups。
想每次關機都自動備份：「詳細資訊」→「這台的設定」勾「正常關機後自動備份世界」。
當機或強制結束後不會自動備份；舊備份不會自動刪，佔太多空間時請自己刪舊的。

要還原時：
1. 先關機。
2. 把伺服器資料夾裡現在的 world 改名留著（例如 world_舊）。
3. 到 backups 裡挑一份，把裡面的 world 資料夾複製回伺服器資料夾。
4. 重新開機。


六、讓朋友連進來（工具不會自動設定，請照下面做）
----------------------------------------------
先確認：狀態是綠色「執行中」、你自己用 localhost 連得進去。第一次開機如果 Windows 問要不要允許 Java 存取網路，請按「允許」。

(1) 朋友和你在同一個網路（同一台分享器）
    按 Win＋R 輸入 cmd，再輸入 ipconfig，找到「IPv4 位址」，例如 192.168.1.23。
    朋友在遊戲裡填 192.168.1.23:連接埠。

(2) 朋友在別的地方：路由器轉埠
    a. 登入家裡路由器的管理頁面，每家不同，可以搜尋「你的路由器型號 port forwarding」。
    b. 新增一條規則：外部埠和內部埠都填畫面上的連接埠，通訊協定 TCP，轉到你這台電腦的 IPv4 位址。
    c. 用瀏覽器搜尋「what is my ip」查到對外 IP，朋友填「對外IP:連接埠」。
    d. 對外 IP 常常會變，想要固定名稱可以申請免費的動態網址（DDNS）。把網址填到「朋友連線網址」，之後按複製就能貼給朋友。
    e. 如果轉埠後還是連不上，可能是電信業者沒有給你真實 IP（CGNAT），請打電話問電信業者，或改用下面的方法。

(3) 朋友在別的地方：穿透服務或虛擬區網（不用動路由器）
    可以搜尋 playit.gg、Tailscale、ZeroTier、Radmin VPN 等服務。這些是第三方服務，設定方式請看它們的官方說明。

安全提醒：
- 把伺服器開放到網路上，任何知道位址的人都能試著連。建議開白名單：
  在指令框輸入 whitelist on，再用 whitelist add 玩家名稱 加入朋友。
- 只把 op（管理員）給你信任的人。
- 不要關掉 server.properties 的 online-mode，關掉後別人可以冒用任何玩家名稱。


七、怎麼更新
------------
1. 視窗上方出現「有新版」提醒時，向給你這個工具的人拿新版壓縮檔。工具不會自己下載或更換程式。
2. 先把伺服器都關機，按「關閉平台」。
3. 解壓縮，用新的「MC開服平台.exe」蓋掉舊的（或直接刪掉舊的）。
4. 雙擊新的 exe。伺服器清單和設定存在別的地方（見第九節），都會留著。

關於「有新版」提醒：每次打開平台時，會到一個固定網址讀一次最新版本號（只有像 1.0.1 這樣的幾個字）。
不會傳送你的帳號、伺服器清單或任何資料；但和打開任何網頁一樣，對方主機會看到你這次連線的 IP。
沒有網路或讀取失敗時不會顯示提醒，也不影響開伺服器。


八、常見問題
------------
Q：按開機後跳出說明，說要 Java？
A：點視窗裡的「開啟下載頁」，安裝畫面上寫的版本，裝好再按一次開機。

Q：紅色訊息寫「連接埠被佔用」？
A：另一台伺服器還開著，或別的程式用了同一個連接埠。先關掉另一台，或改該伺服器 server.properties 裡的 server-port。

Q：紅色訊息寫「記憶體不夠」？
A：先關機，到「詳細資訊」→「這台的設定」把記憶體上限調小，按「套用」。
   （平台會先把原本的啟動檔留一份 .bak 備份。）

Q：紅色訊息寫「模組有問題」？
A：看下方主控台最後幾行寫的是哪個模組，換成符合遊戲版本的檔案，或補上它需要的前置模組。

Q：顯示「在別處執行中」（紫色）？
A：伺服器是從別的黑色視窗開的。請到那個視窗輸入 stop，之後改從平台開。

Q：按了關機超過 2 分鐘還沒關？
A：按鈕會變成紅色的「強制結束」，這是最後手段，可能讓最後幾分鐘的進度沒存到。先看主控台是不是還在存檔。

Q：平台自己不見了？
A：伺服器都關著、視窗也關了約 3 分鐘，平台會自動結束，不佔電腦資源。再雙擊 exe 就好。


九、我的設定存在哪裡？
----------------------
按 Win＋R 輸入 %APPDATA%\MCServerHub。裡面有伺服器清單 hub_config.json 和平台紀錄 hub.log。
exe 可以搬到任何地方、換成新版，清單都不會不見。


十、Mac 版
----------
支援 macOS 11 以上。同一個 app 內含 Intel 與 Apple 晶片（M 系列）兩份原生程式，不用另外裝 Rosetta。
（1.2.0 在 2018 Intel MacBook Pro、macOS 15.8.1 實測；Apple 晶片版本已內含，但尚未在 M 系列 Mac 實機測試。）

第一次打開（約 3 分鐘，只要做一次）：
1. 雙擊下載的「MC開服平台-<版本>-mac.zip」解壓縮，把「MC開服平台」拖到「應用程式」資料夾（放桌面也可以）。
2. 雙擊「MC開服平台」。會跳出「未打開『MC開服平台.app』／Apple 無法驗證…是否為惡意軟體」，
   只有「完成」和「丟到垃圾桶」兩個按鈕：按「完成」。
   （macOS 15 起「按右鍵 → 打開」也是跳一樣的視窗，舊方法已經沒用。）
3. 打開「系統設定」→「隱私權與安全性」，往下捲到「安全性」，
   會看到「已阻擋『MC開服平台.app』…」，按旁邊的「強制打開」（有些版本寫「仍要打開」）。
4. 輸入 Mac 登入密碼（或按 Touch ID），再跳出的視窗按「打開」。
5. 之後直接雙擊就能開，不會再問。換新版時要再做一次第 2–4 步。
會這樣擋，是因為這個工具沒有付費加入 Apple 開發者計畫做簽章與公證，不是偵測到病毒。
zip 旁附的 SHA256 檢查碼可以用「終端機」核對：shasum -a 256 MC開服平台-<版本>-mac.zip

和 Windows 不一樣的地方：
- 啟動檔是 start.sh（Windows 是 start.bat）。平台建的伺服器會自動寫好；
  加入現有資料夾時，請選有 start.sh（或 Forge／NeoForge 安裝器產生的 run.sh）的資料夾。
- 視窗：電腦有 Chrome 或 Edge 就用沒有網址列的 App 視窗，沒有就用預設瀏覽器開。
- Java：請裝 Eclipse Temurin（平台給的下載連結會依 Intel／Apple 晶片給對的版本），裝在「應用程式」或家目錄的
  Library/Java 都找得到，裝好不用重開平台。
- 設定存在：Finder 按 ⌘⇧G 輸入 ~/Library/Application Support/MCServerHub
- 常用指令搜尋：⌘ K。
- 關掉平台視窗伺服器照跑，再雙擊「MC開服平台」就會回到同一個平台。
