MC 開服平台 2.0 使用說明（尚未正式發佈）
========================================

在自己的電腦開 Minecraft Java 版伺服器，管理開關機、玩家、模組與世界備份。
控制介面只走桌面程式內部通道；遊戲伺服器能不能讓外部朋友連線，要另外看網路設定。
本說明以 2.0 為準；安裝驗證歷程見 docs/step11-packaging.md，Mac 與正式發佈待驗項目見 docs/step12-readiness.md。

一、下載、安裝與升級
--------------------
Windows：正式發佈後，在 GitHub Releases 下載 MCServerHub-Setup-Windows.exe 和同版 SHA256SUMS.txt。
先在 PowerShell 執行 Get-FileHash .\MCServerHub-Setup-Windows.exe -Algorithm SHA256，比對檢查碼。
雙擊安裝檔，照畫面操作；程式裝在目前使用者的資料夾，不需管理員權限。
裝好從開始功能表開啟「MC開服平台」，不建立桌面捷徑。
尚未取得程式碼簽章，SmartScreen 可能警告。請先確認來源、檢查碼；不要關防毒或忽略病毒偵測。
若缺 WebView2，正式安裝器可能要求下載執行環境。本機測試包可能不包含這一步。

Mac：正式發佈後下載 MCServerHub-Mac.dmg 和同版 SHA256SUMS.txt。
在終端機執行 shasum -a 256 MCServerHub-Mac.dmg，核對檢查碼後開啟 DMG。
閱讀授權畫面後，把「MC開服平台」拖進「應用程式」，再從那裡開啟。
已有同名程式時，先正常關閉平台與所有伺服器、保留備份，再決定是否替換。
目前 universal DMG 含 Intel／Apple 晶片程式；Intel 已實測，Apple 晶片實機驗收暫緩、仍未驗。
打包下限為 macOS 11，但不是每個系統版本都已測過；目前 Intel 實測為 macOS 15.8.1。
Mac 測試包僅有 ad-hoc 簽章、未公證；網路下載後的 Gatekeeper 流程仍未驗。
若系統阻擋，先核來源與檢查碼，不要全域停用 Gatekeeper 或批次移除下載保護標記。

從 1.x 升級前，先正常關閉所有伺服器並備份世界。
首次啟動 2.0 會備份並匯入舊 hub_config.json，改用 config.json；原設定保留。
不要同時用兩版平台管理同一台伺服器。伺服器資料夾留在原位，不需要搬進程式安裝資料夾。

二、從零建立伺服器
------------------
1. 按左側「建立新伺服器」，填名稱、遊戲版本、類型、記憶體與存放位置。
2. 原版不能裝模組；Fabric／Forge／NeoForge 的模組不能互通，請選和模組相同的類型。
3. 看 Java 檢查結果。缺少時可先查官方下載資訊，核對版本、大小、SHA-256 與來源，確認才安裝。
   平台專用 Java 不改 PATH、系統 Java 或舊啟動檔；自訂 Java 路徑維持原意。
4. 本人閱讀並勾選 Minecraft EULA。平台不代為同意。
5. 按「建立並開機」。送出或下載中不能取消或修改欄位；請看目前進度與錯誤提示。
   Forge／NeoForge 可能下載數百 MB，需約 2–10 分鐘；其他類型通常約 1–3 分鐘。
6. 等狀態變綠色「執行中」再進遊戲。本機連 localhost；自訂連接埠則填 localhost:連接埠。

三、加入已有的伺服器
--------------------
按「加入現有資料夾」，選有 start.bat／run.bat（Mac 為 start.sh／run.sh）的資料夾。
平台讀取版本與連接埠；無法辨識時看提示，不猜改原啟動檔。
「詳細資訊 → 從清單移除」只移除平台登記，不刪資料夾或世界。

四、日常開關機與指令
--------------------
開機：按「開機」，先看 Java／磁碟／連接埠／EULA 檢查，再確認開機。
關機：按「關機」並確認；平台送 stop，先存檔再關。不要直接關電腦或強制結束程序。
主控台：看最新紀錄；可關閉「自動捲到最新」，不會自己跳回底部。
指令：從分類選常用指令、填欄位；或在底下手打，不用加 /。↑↓ 可叫回歷史。
Windows 用 Ctrl K、Mac 用 ⌘ K 搜尋指令；危險指令會再確認，有些要打對象名稱才可執行。
取消指令表單或按 Esc，鍵盤焦點會回到原指令格。
在線顯示「待確認」代表尚未取得資料，不代表沒人。
「詳細資訊」可改朋友連線網址、記憶體、正常關機自動備份、圖示及加入說明。
複製網址或加入說明後，可由你貼給朋友；本工具不自動寄送。

五、管理玩家與遊戲設定
----------------------
按「管理伺服器」。玩家頁同時看線上、OP、白名單與封鎖名單；未知線上資料會明說。
管理 OP、封鎖或踢人前確認帳號。關機修改名單會先備份；執行中則交給遊戲指令處理。
不知道離線玩家 UUID 時不要猜，先核對或等開機後用名稱操作。
遊戲設定先列常用 15 項，其餘放進階。儲存前留原檔備份；執行中儲存後需重開生效。
外部也改過檔案時不會靜默覆蓋，可放棄草稿並重新讀取。
切頁、指令搜尋或關窗前會保護尚未儲存的設定；忙碌中先等結果，不要反覆送出。

六、備份與還原
--------------
關機時按「備份世界」，或到「管理伺服器 → 備份與還原」建立與還原。
「詳細資訊」可選正常關機後自動備份；當機或強制結束不會冒充正常備份。
「設定 → 備份」可調位置、保留份數（預設 10）與每日時間；排程在平台開著時才嘗試。
還原前固定保存目前世界快照，再驗證備份並替換；失敗會嘗試回復原世界。
快照、未完成及未知舊備份不算一般保留份數，可能額外占空間。
交易中斷會阻擋開機並留下救援資料；遇到這類提示先保留現場，不自行刪 marker 或強開。
重要世界另留一份離機備份；不要把伺服器或世界存進平台程式安裝資料夾。

七、模組與重開
--------------
模組管理先核對這台的遊戲版本與載入器，再搜尋 Modrinth。
先檢查必要相依和完整變更清單，關機後確認才下載及套用；原模組先備份，失敗嘗試回復。
平台只自動管理自己安裝的模組，其他模組保留原狀。相同版本不保證整包遊戲相容。
不會自動升級 Minecraft；模組開服遊戲相容仍需自行確認。

自動重開預設關閉。當機重試有等待與次數上限；手動關機會取消待重開。
每天定時重開依本機時間、平台開著才執行：先廣播倒數，再正常停服，備份完成並重檢才開機。
停服、外部執行或當天已嘗試就不補做；關機失敗不強制重開，也不無限重試。

八、平台設定、更新與解除安裝
----------------------------
「設定」調登入啟動、啟動縮小、關窗行為、自動開服、深淺色、字級、音效與音量。
關窗可選結束平台或縮到系統匣；結束時若仍有服或工作在執行會阻擋。點系統匣圖示可叫回視窗。
重複開啟會叫回原視窗，不另開第二份。
Mac 選單「結束 MC開服平台」與 ⌘ Q 也會先檢查執行中工作及未儲存草稿；有工作時不直接退出。
檢查更新可關閉。按「更新」才下載，核對簽章與版本；伺服器或工作忙碌時不更新。
Windows 已驗連不到更新服務時會提示原程式與設定保留，且可再次檢查；Mac 更新流程仍待實機驗證。
這項檢查失敗驗證不代表正式更新的下載、驗簽或安裝已驗收。
診斷資訊只存本機，不自動上傳；分享前仍請自己看過檔案。

設定位置：Windows %APPDATA%\MCServerHub\；Mac ~/Library/Application Support/MCServerHub/。
Windows 解除安裝從「設定 → 應用程式」進行，只移除平台程式與安裝登記；設定、世界與伺服器保留。
Mac 登入啟動尚未實機驗證；若曾啟用，移除程式前需另外確認登入項目，不能把移除 app 當作完整清理。
要重設設定請在平台進階設定操作，會先備份；它不等於刪除世界。
